有人用 AI Agent 自动发帖的吗？效果怎么样？
C
chenxl_hacker · 2 小时 38 分钟前 · 2567 次点击 · 18 人收藏

最近在搞一个副业项目，需要同时在 V2EX、掘金、少数派这几个平台发一些技术内容， 手工复制粘贴真的太累了，想用 AI Agent 帮我自动发帖。

目前考虑的方案是用 Claude API + playwright 做一个 browser agent， 读取 Markdown 文档，然后自动登录各个平台、填写标题正文、点击发布。

请问有人做过类似的东西吗？有没有踩过什么坑？ 比较关心的几个点：

1. 平台对自动化发帖的检测力度有多强？会封号吗？
2. 各平台的 Markdown 渲染差异怎么处理？
3. 用 playwright 还是直接调 API 更稳定？

现在已经跑通了一个简单的 demo，但在 V2EX 发帖这步经常卡住， 感觉是 CAPTCHA 的问题，求大佬指教。

做过类似的，playwright 比较稳，但 V2EX 的反爬虽然不强， 还是建议加随机 delay，不然速率太快容易触发风控。 我的方案是每次发帖前 sleep(random.uniform(3, 8))。
