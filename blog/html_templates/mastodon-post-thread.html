🎉 Just shipped dotwave v2.0 — a terminal dotfile manager written in Rust.

New in this release:
• Declarative TOML config with per-machine overrides
• Atomic symlink swaps (no broken states on failure)
• Built-in secret masking for shell history

Crate: crates.io/crates/dotwave
